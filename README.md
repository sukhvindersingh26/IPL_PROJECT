# IPL Project

## Project Overview
This project analyzes IPL cricket match data using Python and MySQL to generate insights into team and player performance. The goal is to demonstrate practical data analysis and visualization skills.

## Features
- Connects to *MySQL database* to fetch IPL match data.
- Converts data into *Pandas DataFrame* for analysis.
- Performs analysis for:
  - Total matches
  - Wins per team
  - Top 5 players of each match
  - Average runs per team
- Visualizes data using *Matplotlib Bar Chart*.

## Technologies Used
- *Python*: Data analysis
- *Pandas*: Data aggregation and manipulation
- *Matplotlib*: Visualization
- *MySQL*: Database for IPL match data
